# 🤖 KnowBaseBot

**Telegram-бот с искусственным интеллектом, который превращает ваши заметки в интерактивные тесты и помогает эффективно учиться.**

---

## 📖 О проекте

KnowBaseBot — это умный помощник для тех, кто работает с большими объёмами текстовой информации. Вы загружаете в бота файлы в формате `.md` (Markdown), а он автоматически генерирует вопросы по этому материалу, оценивает ваши ответы и сохраняет статистику прогресса.

Бот идеально подходит для студентов, исследователей, разработчиков и всех, кто практикует интервальное повторение и активное обучение.

### 💡 Ключевая особенность — Экономия токенов
Вместо генерации одного вопроса за один запрос к ИИ (что дорого), бот использует стратегию **пакетной генерации**: за один вызов API создаётся пул из 15 вопросов, которые сохраняются в базе данных. Пользователь затем проходит их по одному **без дополнительных затрат токенов**. Это снижает расходы на ИИ в 10-15 раз!

## ✨ Основные возможности

### 👤 Для пользователя:
- 📂 **Управление базой знаний**: Загрузка, просмотр и удаление файлов Markdown с автоматической генерацией описания через ИИ.
- 🧠 **Умная викторина**:
  - 🎲 **Генерация пула вопросов**: Выберите файл → получите 15 вопросов за один запрос к ИИ.
  - 📝 **Ответ на пропущенные**: Проходите ранее сгенерированные вопросы без затрат токенов.
  - 🎙️ **Голосовые ответы**: Отвечайте голосом — бот распознает речь через Vosk.
- ⚙️ **Настройка сложности**: Выбор уровня вопросов (Легкий, Средний, Сложный).
- 📊 **Аналитика**: Отслеживание прогресса, статистика правильных ответов, средний балл и мини-графики динамики.
- 🔔 **Напоминания**: Ежедневные уведомления в 9:00 для мотивации к обучению.
- 💬 **Обратная связь**: Возможность отправить отзыв разработчикам прямо из бота.

### 🛡️ Для администратора (Владельца):
- 🔐 **Админ-панель**: Полный контроль над пользователями и лимитами.
- 📈 **Глубокая статистика**: Расход токенов (генерация + оценка), количество сгенерированных вопросов, активность пользователей.
- 🗂 **Модерация отзывов**: Просмотр, пометка как прочитанные и управление отзывами пользователей.
- 📅 **Ежедневные отчёты**: Автоматическая утренняя сводка по активности бота в 7:00.
- 📊 **Экспорт в Excel**: Выгрузка детального отчёта по пользователю за 30 дней с цветовой индикацией результатов.

## 🛠️ Технологический стек

- **Язык**: Python 3.10+
- **Фреймворк**: [Aiogram 3.x](https://docs.aiogram.dev/) (полностью асинхронный)
- **База данных**: SQLite + SQLAlchemy 2.0 (асинхронный ORM, WAL-режим для производительности)
- **AI**: OpenAI API Compatible (поддерживает OpenAI, Gemini, Anthropic, VedaAI и др.)
- **Распознавание речи**: [Vosk](https://alphacephei.com/vosk/) (локальная модель, без внешних API)
- **Конвертация аудио**: FFmpeg (OGG → WAV)
- **Планировщик**: APScheduler (для напоминаний и ежедневных отчётов)
- **Логирование**: Loguru (структурированные JSON-логи с ротацией)
- **Контейнеризация**: Docker & Docker Compose

## 🚀 Установка и запуск

Самый простой и надёжный способ запуска — использование Docker.

### 1. Требования
- Установленный Docker и Docker Compose
- Git (для клонирования репозитория)
- Минимум 500 МБ свободного места на диске (для модели Vosk)

### 2. Клонирование репозитория
```bash
git clone https://github.com/luhverchikv/KnowBaseBot.git
cd KnowBaseBot
```

### 3. Настройка переменных окружения
Создайте файл `.env` в корне проекта на основе примера:

```bash
cp .env.example .env
```

Отредактируйте файл `.env`:
```ini
BOT_TOKEN=ВАШ_ТОКЕН_ОТ_BOTFATHER
OWNER_ID=ВАШ_ID_В_TELEGRAM

# База данных (SQLite)
DB_URL=sqlite+aiosqlite:///database/knowbase.db

# AI провайдер (совместимый с OpenAI API)
AI_API_KEY=ваш-api-ключ
AI_BASE_URL=https://api.openai.com/v1
AI_MODEL=gpt-3.5-turbo
AI_TEMPERATURE=0.7
AI_MAX_TOKENS=500
```

### 4. Запуск через Docker Compose
Соберите и запустите контейнеры в фоновом режиме:

```bash
docker compose up -d --build
```

Для просмотра логов:
```bash
docker compose logs -f
```

## 🧠 Как работает экономия токенов?

### Старый подход (1 вопрос = 1 запрос):
```
Пользователь → Бот → ИИ (генерация 1 вопроса) → Пользователь
Пользователь → Бот → ИИ (генерация 1 вопроса) → Пользователь
Пользователь → Бот → ИИ (генерация 1 вопроса) → Пользователь
```
❌ 3 вопроса = 3 запроса к API = высокие затраты

### Новый подход (пакетная генерация):
```
Пользователь выбирает файл → Бот → ИИ (генерация 15 вопросов за 1 запрос)
                                    ↓
                              Сохранение в БД
                                    ↓
Пользователь → Бот → БД (1-й вопрос) → Пользователь
Пользователь → Бот → БД (2-й вопрос) → Пользователь
Пользователь → Бот → БД (3-й вопрос) → Пользователь
...
```
✅ 15 вопросов = 1 запрос к API = **экономия ~90% токенов**

## ⚙️ Конфигурация AI

Бот поддерживает любые провайдеры, совместимые с форматом OpenAI API. В файле `.env` вы можете указать прокси или локальный сервер (например, Ollama или LocalAI), изменив `AI_BASE_URL`.

**Пример настройки для VedaAI:**
```ini
AI_BASE_URL=https://vedai.by/api/v1
AI_MODEL=gemini-2.5-flash-lite
```

**Пример настройки для локальной модели (Ollama):**
```ini
AI_BASE_URL=http://localhost:11434/v1
AI_MODEL=llama3
```

## 🗄️ Структура базы данных

### Таблица `users`
Хранит профили пользователей с индивидуальными лимитами (файлы, размер, вопросы/день), настройками сложности и напоминаний.

### Таблица `quiz_questions`
Содержит сгенерированные вопросы с полной историей:
- Текст вопроса, правильный ответ, ответ пользователя
- Результат оценки (правильно/частично/неправильно)
- Обратная связь от ИИ и рейтинг (1-5 звёзд)
- **Детальная статистика токенов**: `gen_total_tokens`, `eval_total_tokens`

### Таблица `files`
Метаданные загруженных файлов: имя, путь на диске, AI-описание, дата добавления.

### Таблица `feedback`
Отзывы пользователей с пометкой о прочтении.

1. Отправьте боту команду `/admin`

   - 👥 Управлять профилями пользователей

   - 💬 Читать и удалять отзывы от пользователей
   - 📊 Выгружать детальные Excel-отчёты по любому пользователю

## 📦 Резервное копирование

Так как бот использует SQLite, базу данных можно легко скопировать вручную:

```bash
# Остановите бота
docker compose stop

# Скопируйте файл базы данных
docker cp knowbase-bot:/app/database/knowbase.db ./backup/database_$(date +%F).db

# Скопируйте файлы пользователей
docker cp knowbase-bot:/app/database ./backup/user_files_$(date +%F)/

# Запустите бота снова
docker compose start
```

## 🛡️ Отказоустойчивость

- **WAL-режим SQLite**: Улучшенная производительность и надёжность при одновременных записях
- **Обработка ошибок БД**: При переполнении диска бот показывает понятное сообщение пользователю
- **Ротация логов**: Логи автоматически сжимаются и удаляются через 2 недели
- **Автоматические повторные попытки**: AI-клиент делает до 3 попыток при сбоях API
- **Graceful shutdown**: Корректное завершение работы при остановке контейнера
