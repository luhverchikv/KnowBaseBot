# 🤖 KnowBaseBot

**Telegram-бот с искусственным интеллектом, который превращает ваши заметки в интерактивные тесты и помогает эффективно учиться.**

---

## 📖 О проекте

KnowBaseBot — это умный помощник для тех, кто работает с большими объемами текстовой информации. Вы загружаете в бота файлы в формате `.md` (Markdown), а он автоматически генерирует вопросы по этому материалу, оценивает ваши ответы и сохраняет статистику прогресса.

Бот идеально подходит для студентов, исследователей, разработчиков и всех, кто практикует интервальное повторение и активное обучение.

---

## ✨ Основные возможности

### 👤 Для пользователя:
- 📂 **Управление базой знаний**: Загрузка и хранение файлов Markdown.
- 🧠 **Генерация тестов**: AI создает уникальные вопросы на основе загруженного контента.
- ⚙️ **Настройка сложности**: Выбор уровня вопросов (Легкий, Средний, Сложный).
- 📊 **Аналитика**: Отслеживание прогресса, статистика правильных ответов и средний балл.
- 🔔 **Напоминания**: Ежедневные уведомления для мотивации к обучению.
- 💬 **Обратная связь**: Возможность отправить отзыв разработчикам прямо из бота.

### 🛡️ Для администратора (Владельца):
- 🔐 **Админ-панель**: Полный контроль над пользователями и лимитами.
- 📈 **Глубокая статистика**: Расход токенов, количество сгенерированных вопросов, активность пользователей.
- 🗂 **Модерация отзывов**: Просмотр и управление отзывами пользователей.
- 📅 **Ежедневные отчеты**: Автоматическая сводка по активности бота каждое утро.

## 🛠️ Технологический стек

- **Язык**: Python 3.10+
- **Фреймворк**: [Aiogram 3.x](https://docs.aiogram.dev/) (асинхронный)
- **База данных**: SQLite (встроенная, легкая и надежная)
- **AI**: OpenAI API Compatible (поддерживает OpenAI, Gemini, Anthropic и др.)
- **Планировщик**: APScheduler (для напоминаний и отчетов)
- **Контейнеризация**: Docker & Docker Compose

## 🚀 Установка и запуск

Самый простой и надежный способ запуска — использование Docker.

### 1. Требования
- Установленный Docker и Docker Compose.
- Git (для клонирования репозитория).

### 2. Клонирование репозитория
```bash
git clone https://github.com/ваш-профиль/KnowBaseBot.git
cd KnowBaseBot
```

### 3. Настройка переменных окружения
Создайте файл `.env` в корне папки на основе примера и заполните его вашими данными:

```bash
cp .env.example .env
```

Отредактируйте файл `.env`:
```ini
BOT_TOKEN=ВАШ_ТОКЕН_ОТ_BOTFATHER
OWNER_ID=ВАШ_ID_В_TELEGRAM
AI_API_KEY=ВАШ_API_KEY_AI
AI_BASE_URL=https://api.openai.com/v1
AI_MODEL=gpt-3.5-turbo # Или другая модель, например gemini-pro
```

### 4. Запуск через Docker Compose
Соберите и запустите контейнеры в фоновом режиме:

```bash
docker compose up -d --build
```

Для просмотра логов:
```bash
docker compose logs -f
```

## ⚙️ Конфигурация AI

Бот поддерживает любые провайдеры, совместимые с форматом OpenAI API.
В файле `.env` вы можете указать прокси или локальный сервер (например, Ollama или LocalAI), изменив `AI_BASE_URL`.

**Пример настройки для локальной модели:**
```ini
AI_BASE_URL=http://localhost:11434/v1
AI_MODEL=llama3
```

## 👮‍♂️ Использование админ-панели

1. Отправьте боту команду `/admin`.
2. Доступ разрешен только тому `user_id`, который указан в `OWNER_ID`.
3. В панели вы можете:
   - Посмотреть общую статистику.
   - Управлять лимитами пользователей (количество файлов, лимит генерации).
   - Читать отзывы от пользователей.
   - Посмотреть расход токенов.

## 📦 Резервное копирование

Так как бот использует SQLite, базу данных можно легко скопировать вручную:

```bash
# Остановите бота
docker compose stop

# Скопируйте файл базы данных
docker cp knowbase-bot:/app/database/database.db ./backup/database_$(date +%F).db

# Запустите бота снова
docker compose start
```
